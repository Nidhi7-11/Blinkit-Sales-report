An interactive Power BI dashboard built to analyze Blinkit’s sales, inventory, and product performance.
This project provides meaningful insights through visualizations to support data-driven decision-making.

Objectives
  Analyze overall sales performance
  Track product category-wise sales
  Monitor outlet performance
  Understand customer purchasing patterns
  Identify high and low-performing products

Dashboard Features
  Sales Overview – Total sales, average sales, number of items and checked ratings
  Outlet Analysis – Performance by outlet type and size
  Product Insights – Category-wise and item-wise analysis
  Trend Analysis – Sales trends over time
  Interactive Filters – Easy slicing by outlet, category, and location

  Tools & Technologies
  Power BI Desktop (.pbix)
  Data Cleaning & Transformation using Power Query
  Data Modeling using relationships
  DAX (Data Analysis Expressions) for calculations

  Key Insights 
    Low Fat and Regular product categories contribute the highest sales
    Medium-sized outlets generate more revenue
    Tier 3  location's  outperform others in sales
    Some products have low visibility but high potential
